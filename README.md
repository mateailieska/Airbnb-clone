# Airbnb Clone

A full-stack Airbnb-inspired web application developed as a team assignment.

## Technologies

- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- JWT
- PostgreSQL
- React
- Docker

## Features

- User authentication and authorization
- Property listings
- Property search
- Booking system
- Reviews
- Wishlist
- User trips

## My Contribution

As part of the development team, I worked on:

- Backend development with Spring Boot
- REST API development
- DTOs, services and controllers
- Authentication and authorization using Spring Security and JWT
- Database integration with PostgreSQL
- Frontend features and integration with the backend

## Project Structure

- `src/` — Spring Boot backend
- `frontend/` — React frontend
